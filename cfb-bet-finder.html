The big number on each card is the modeled win probability (consensus across books, de-vigged). "Edge" is a separate, smaller number \u2014 how much better the best book's price is than that consensus suggests. Raw edge size alone tends to favor longshots, since underdogs get thinner, more inconsistent coverage across books than favorites do, which is why there's a win-probability filter above (defaults to 50%+) instead of sorting by edge size alone. Spread and total edges only count books quoting the exact same point \u2014 different numbers aren't compared as if equivalent. 1st-half odds are fetched per game on tap (not automatically, to conserve API quota) using the same de-vig method. Uses your own free-tier API quota (usually 500 requests/month); the main scan costs ~3 requests (moneyline+spread+total), each half-check costs ~1 more. This is a stats/odds-comparison tool, not financial or betting advice.
