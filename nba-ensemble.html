NBA ENSEMBLE MODEL

Three independent models that learn from last season, plus a possession simulator for totals. Train on 2025–26, see each model's out-of-sample accuracy, and the slate uses what it learned.

SETTINGS
No API key. Injuries load automatically from ESPN's report. Each absent player's value comes from his per-game production harvested during Four Factors training; without that, a flat default is used and flagged. Every impact can be edited or skipped inside the card.
TRAIN ON A SEASON — WALK-FORWARD
Walks the season in order. Every game is predicted using only games before it, then the models are refit. Warm-up games train but are not scored. Results and learned parameters save to this browser so the slate uses them.
Bankroll note. Published accuracy claims for these model families (67–74%) come from academic samples with their own feature sets; the number to trust is the one this trainer reports on games it never saw.

Bradley–Terry ratings are fit by maximum likelihood on game outcomes with L2 shrinkage, plus a shared home-advantage term and a back-to-back fatigue term, exactly the logit form shown. Margin ratings are fit by least squares on point differential with a home term; win probability is the normal CDF of the predicted margin over the residual standard deviation measured out of sample. The Four Factors regression uses each team's season-to-date eFG%, TOV%, ORB% and FT rate (offence minus what the opponent allows), computed only from games before the one being predicted; it requires one box-score request per game. Walk-forward means models are refit on an expanding window and every scored prediction is genuinely out of sample; warm-up games are excluded from scoring. Ensemble weights are the inverse of each model's out-of-sample Brier score, normalised. Totals come from margin-model offensive and defensive point ratings with the fitted total residual spread. Injuries are read from ESPN's report at run time; a player marked Out is charged his full estimated impact and Day-to-Day the chosen fraction. Impact is production above a replacement line (points plus 0.7×rebounds plus 0.7×assists, minus 8, times 0.18), capped at 6.5 points so no single absence exceeds a superstar's usual effect on the spread; it is a transparent heuristic, not a plus-minus model, and every value is editable. The adjustment moves the margin model directly and Bradley–Terry through the points-per-logit ratio implied by both models' fitted home terms. Injury adjustments cannot be backtested because ESPN's report is current only, so their effect on accuracy is not measured here. The possession simulator and referee, coach-rotation and in-game fatigue layers described in the source are not reproducible from public box scores and are not claimed here; rest is. This is a research tool, not betting advice.
