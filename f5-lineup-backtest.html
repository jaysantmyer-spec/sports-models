F5 LINEUP COMPARISON BACKTEST

For every game: pulls both starting lineups and starting pitchers with handedness, computes each lineup's average split-adjusted rate stats against the opposing starter's throwing hand, and tests whether the superior lineup actually won the first five innings.

Split-stat mode is determined on the first request and reported here. Date-bounded splits are required for an honest test; season-wide splits would let a game's own result influence its own prediction.
RANGE
Results accumulate across runs and persist in this browser, so a full season can be built up in chunks. Expect roughly 10–20 seconds per game day.

Method: starting lineups are taken from each game's box score (batting order positions ending in 00), with handedness from each player's registry entry. Switch hitters are assigned the platoon advantage, batting opposite the starter's throwing hand. Each batter's rate stats are queried against the specific split matching the opposing starter's hand — left-handed starter returns the batter's numbers against left-handed pitching. Lineup figures are unweighted means across qualifying starters, matching the described methodology. wOBA is computed from split components using standard linear weights, which drift slightly year to year, so treat it as closely approximate rather than exact. xBABIP is not published by Statcast directly and is derived here as expected hits minus home runs, over balls in play, using the batter's expected batting average against their actual split counting stats. Statcast expected stats are pulled once per season as a bulk leaderboard and are season-wide rather than platoon-split, which is a genuine mismatch against the handedness-specific rows above and is flagged in the results rather than papered over. If Savant refuses the cross-origin request, those rows are omitted entirely rather than estimated. F5 outcome is read from the line score across innings one through five; ties are excluded from all percentages, as in the reference table. A stat is scored correct when the lineup with the higher average in that stat won the first five innings. This measures directional agreement only and is not a betting model: it carries no price, no vig, and no market comparison.
