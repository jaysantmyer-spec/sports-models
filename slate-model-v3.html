SLATE MODEL v3 — FIRST FIVE

The v2 team model, now projecting first-five-innings runs from BaseRuns and the two starters. Gives an F5 moneyline with push handling, an F5 total with an over/under bar, and a proper backtest that only uses stats available before each game.

1. BaseRuns per game (offence) and allowed per game (defence), from stats through the day before
2. Each side's F5 run rate = league F5 baseline × offence factor × opponent-defence factor × starter factor (FIP vs league) × park
3. 20,000 Poisson draws per side → F5 win / tie / total distribution
4. Moneyline is quoted on non-tie outcomes only, since an F5 ML pushes on a tie
SETTINGS
No API key needed. Every computed value can be overridden inside a card. F5 uses starters only; bullpens are excluded by design.
BACKTEST — PRE-GAME STATS ONLY
Walks back day by day until it has the target number of completed games. Each game is projected using team stats through the day before and each starter's stats through the day before, so no result feeds its own prediction. Expect roughly a minute per 10 games.
Bankroll note. Even a sound model loses roughly 40–45% of the time to variance. Never wager money you cannot afford to lose.

F5 projection: each team's per-game BaseRuns scored and allowed are converted to factors against the league average, then combined with the opposing starter's FIP relative to league (scaled by their typical start length as a share of five innings) and an approximate park factor, applied to a 2.55-run-per-team F5 baseline. Runs are simulated as Poisson draws, which slightly understate the variance of real innings, so extreme totals are a touch rarer in the model than in life. An F5 moneyline pushes on a tie; the quoted probability is therefore conditional on a decision, and the tie rate is shown separately. The over/under bar shows the model's three-way split at the entered line: over, push (exact), under. Backtest calibration compares stated confidence to realised hit rate in bands, which is the informative check: a well-calibrated 65% band wins about 65% of the time. Caught stealing and grounded-into-double-play totals absent from the pitching feed are estimated from at-bats so both sides of the ledger stay symmetric; supplied values are never overwritten. This is a research tool, not betting advice.
