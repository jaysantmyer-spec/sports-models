SLATE MODEL v2

BaseRuns and Log 5, now adjusted for the actual starting pitchers, recent form and home field — with every input editable and finished games graded against the result.

1. BaseRuns → deserved runs scored and allowed
2. Adjusted Pythagorean → deserved win rate
3. Starter adjustment → shifts each side by its starter's run prevention vs league
4. Log 5 → matchup probability, then home-field applied as an odds shift
SETTINGS
No API key needed. Recent form costs four extra requests per team, so it runs slower. Every computed value can be overridden inside a game card.
Bankroll note. Even a sound model loses roughly 40–45% of the time to variance. Never wager money you cannot afford to lose.

BaseRuns and Log 5 are unchanged from their published forms. The starter adjustment converts each probable pitcher's FIP into runs prevented relative to league average across their typical start length, then into a win-probability shift at roughly one run per ten points; it is applied to each team's deserved win rate before Log 5 and is capped so a single start cannot dominate season-long quality. Home field is applied after Log 5 as an odds-ratio shift rather than baked into either team's rating. Caught stealing and grounded-into-double-play totals are usually absent from the pitching feed; a zero there is read as missing and estimated from at-bats, since treating it as real understates defensive outs and drags every rating down by roughly eight points of win percentage. Supplied values are never overwritten. Recent-form weighting blends the last thirty days against season totals at the stated weight. Finished games are graded on whether the higher-probability side won, which measures directional accuracy only and says nothing about whether a price was beatable. Season statistics for a past date include games played after it, so grading a historical slate flatters the model; treat the accuracy figure as valid only for dates graded live.
