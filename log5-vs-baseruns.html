LOG 5 vs BASERUNS — SIDE BY SIDE

Every game today run three ways: Log 5 on actual runs, Log 5 on BaseRuns-deserved runs, and an adjustable blend. Finished games grade all three so the app tells you which is more accurate.

Log 5 (actual) — Pythagorean from real runs scored and allowed → Log 5
BaseRuns (deserved) — BaseRuns scored and allowed → Pythagorean → Log 5
Blend — weighted mix of the two, weight set below. Both sides get the same starter and home-field treatment so the only difference is actual vs deserved runs.
SETTINGS
No API key needed. Every value can be overridden inside a card. Use the scoreboard after a few graded days to decide where to set the blend weight.
BACKTEST — PRE-GAME STATS ONLY
Walks back day by day until it has the target count. Each game uses team and starter stats through the day before via date-bounded queries, so nothing leaks. Honours the exponent, blend method, starters and home-field settings from the slate tab. Expect about a minute per 10 games.
Bankroll note. Even a sound model loses roughly 40–45% of the time to variance. Never wager money you cannot afford to lose.

Both Log 5 and BaseRuns are implemented exactly as published. The two side-by-side methods differ only in what feeds the Pythagorean step: actual runs scored and allowed versus BaseRuns-deserved runs; starter adjustment and home field are applied identically to both so the comparison isolates the sequencing question. The blend is a straight weighted average of the two win probabilities at the slider weight. The full-game total projection uses BaseRuns per game for each offence against the opponent's BaseRuns-allowed per game and the opposing starter's FIP share, simulated as Poisson draws on a 4.45-run baseline; Poisson slightly under-disperses real innings. Caught stealing and grounded-into-double-play totals absent from the pitching feed are estimated from at-bats so both sides of the ledger stay symmetric; supplied values are never overwritten. Grading is directional only and says nothing about whether a price was beatable. Season stats for a past date include games after it, so grading a historical slate flatters every method equally; the scoreboard is honest only for slates run live.
