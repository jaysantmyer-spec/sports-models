F5 RUN PROJECTOR

Projects first-five-innings runs for both sides of today's slate, then compares against any line you enter. No API key required.

Expected F5 Runs = ( Adjusted Pitcher ERA + Lineup Run Rate ) ÷ 2 × 5/9 × Park × Weather
Adjusted ERA = ERA × (pitcher wOBA allowed ÷ league wOBA). Lineup Run Rate converts the opposing lineup's split wOBA onto the same runs-per-nine scale, so the two terms can legitimately be averaged.
SETTINGS
Wind is applied globally because determining whether wind blows out requires each stadium's field orientation, which is not available here. Measured speed and direction are shown per game so the setting can be applied with judgment.

Pitcher wOBA allowed is computed from the counting stats surrendered using standard linear weights; those weights drift slightly by season, so treat wOBA figures as closely approximate. Lineups are the team's top plate-appearance leaders rather than posted lineups, since confirmed cards are not published until shortly before first pitch. Each hitter's wOBA is drawn from their split against the opposing starter's throwing hand; switch hitters are credited with the platoon advantage. Park factors are general reference values, not five-inning-specific figures, and are applied to the run estimate directly. Win probability comes from twenty thousand Poisson simulations per game using each side's projected F5 runs, with ties reported separately because a first-five moneyline pushes on a tie — the quoted win probability is therefore conditional on the game not being tied. Bullpens are deliberately excluded, matching the market. This is a projection tool, not betting advice, and no model output is a guarantee.
