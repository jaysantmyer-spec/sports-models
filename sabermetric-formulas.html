SABERMETRIC FORMULAS

Four standard formulas, implemented exactly as written. Pull real stats from any season, or enter values by hand.

FIELDING INDEPENDENT PITCHING
Estimates a pitcher's run prevention based only on actions they control (strikeouts, walks, hit-by-pitches, and home runs).
FIP = (13 × HR) + (3 × [BB + HBP]) − (2 × SO) IP + FIP Constant
The FIP Constant normalizes the result to a standard ERA scale, usually around 3.10 to 3.20.

WINS ABOVE REPLACEMENT
Estimates the number of wins a player contributes compared to a replacement-level minor leaguer or bench player.
Position Player WAR = Batting Runs + Base Running + Fielding + Positional + League + Replacement Runs per Win
COMPONENT RUNS
These six component runs are produced by full defensive and positional models and are not published by the MLB Stats API, so they are entered by hand. Runs per Win typically sits near 10 and varies with the league run environment.

FIP, Pythagorean Expectation, Runs Created and Position Player WAR are implemented exactly as specified, with no alteration to their structure, terms or exponents. Player and team statistics are pulled from the MLB Stats API, which requires no key. Every input remains editable after loading, so figures from any source can be substituted. Each result shows its full arithmetic so the calculation can be checked rather than taken on trust. Note that FIP as written is undefined at zero innings pitched, Pythagorean Expectation is undefined when a team has neither scored nor allowed a run, and Runs Created is undefined when at-bats plus walks is zero; each calculator reports these cases rather than returning a misleading number.
